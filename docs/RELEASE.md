# Releasing Pavurio

## 1. One-time setup
1. `npm i -g eas-cli && eas login && eas init` (writes `extra.eas.projectId` into app.json).
2. Bundle ids are `com.pavurio.app` (iOS and Android). Change them in `app.json` before the first build if you own another id.
3. **RevenueCat** (optional; without it the paywall shows "Not available yet" and nothing can be bought):
   - Create the app in RevenueCat, an entitlement named **`pro`**, and a current offering with the packages you want (monthly / annual / lifetime are recognised).
   - Add the public SDK keys as EAS environment variables: `EXPO_PUBLIC_RC_IOS_KEY`, `EXPO_PUBLIC_RC_ANDROID_KEY`.
4. App Store privacy answers: no data collected (everything stays on the device; no analytics, no accounts).

## 2. Builds
| Profile | Use |
|---|---|
| `eas build -p ios --profile preview` / `-p android --profile preview` | internal testing (APK on Android) |
| `eas build --profile production` then `eas submit` | store release (build numbers auto-increment) |

The JS can then be updated over the air with `eas update --channel production` (runtime version follows the app version).

## 3. QA checklist before submitting
- `npm run typecheck && npm test`
- Fresh install → onboarding (dog and cat) → reminders step asks for notification permission once.
- Create a routine 2 minutes ahead → the notification arrives → tapping it opens the log card → saving ticks the routine.
- Undo a log that ticked a routine → the routine reopens.
- Walk timer: start, kill the app, reopen → time kept; finish → walk logged and the dog plays the walk clip.
- Records: attach a camera photo and a PDF, kill the app, reopen → attachments still open.
- Story: share a slide and save to Photos (permission prompt shows the French text on a French device).
- Switch the language to Français in Settings; check every tab.
- Delete a pet → its reminders disappear (check pending notifications) and its files are removed.
- Accessibility: VoiceOver/TalkBack through the tab bar, Home quick row, agenda buttons.

## 4. Assets
The dog clip sheets (~41 MB of WebP) are bundled on purpose so the app works fully offline from the first launch. If the binary size ever matters, move every clip except `idle` and `celebrate` to a CDN and load them by URI in `src/animation/dogClips.ts` (generated by `tools/art/clips.py`).

## 5. Widgets and Live Activity (not in 1.0)
They need native targets (`@bacons/apple-targets` for a SwiftUI WidgetKit extension + ActivityKit, and an App Group so the app can share "today's progress / next up" with the widget; on Android a Glance widget). They can't be built or verified without a native build, so they are planned for 1.1 rather than shipped untested.
