### App Privacy ("nutrition label")

**Do you or your third-party partners collect data from this app?** Yes.

| Data type | Collected | Linked to the user | Used for tracking | Purpose |
|---|---|---|---|---|
| Contact Info → **Email Address** | Yes (when they save an account; email+password addresses are confirmed with a code) | Yes | No | App Functionality; Developer’s Advertising or Marketing (newsletter, only with opt-in) |
| Identifiers → **User ID** | Yes | Yes | No | App Functionality |
| User Content → **Other User Content** (pet care data in the backup) | Yes | Yes | No | App Functionality |
| Purchases → **Purchase History** | Yes | Yes | No | App Functionality |
| Diagnostics → **Crash Data** | Yes | Yes | No | App Functionality |
| Usage Data → **Product Interaction** (screens opened, setup steps, care logged; no free text) | Yes, unless turned off in Settings → Help improve Pavurio | No | No | Analytics |
| Identifiers → **Device ID** (Firebase Analytics app instance ID; no advertising identifier, no IDFA) | Yes, unless turned off | No | No | Analytics |

Photos and attachments are backed up to the user's account (Cloud Storage), so declare **Photos** and **Files and docs** as collected for App functionality, linked to the user, not used for tracking. Answer **not collected** for everything else, including Videos, Location, Contacts, Health & Fitness (pet data is not the user's health), Browsing History, Search History and Advertising Data.

**Tracking:** No. You don't need the App Tracking Transparency prompt.

### Data safety form

**Does your app collect or share any of the required user data types?** Yes. Data is collected, **not shared**.

**Is all of the user data collected by your app encrypted in transit?** Yes.

**Do you provide a way for users to request that their data is deleted?** Yes:

- in the app: Settings → Account → Delete account;
- on the web: https://pavurio.com/delete-account.html

**Data types collected:**

| Category → type | Collected | Optional? | Purposes |
|---|---|---|---|
| Personal info → **Email address** | Yes | Optional (only if the user saves an account) | Account management, App functionality, Developer communications (newsletter, opt-in) |
| Personal info → **User IDs** | Yes | Required | Account management, App functionality |
| App activity → **Other user-generated content** (pet care data backup) | Yes | Required | App functionality |
| Financial info → **Purchase history** | Yes | Optional (only buyers) | App functionality |
| Photos and videos → **Photos** (photo backup) | Yes | Required | App functionality |
| Files and docs → **Files and docs** (attachment backup) | Yes | Required | App functionality |
| App info and performance → **Crash logs** | Yes | Optional (can be turned off in the app) | Analytics: fixing crashes |
| App info and performance → **Diagnostics** | Yes | Optional | Analytics: fixing crashes |
| App activity → **App interactions** (screens opened, setup steps, care logged; no free text) | Yes | Optional (Settings → Help improve Pavurio) | Analytics |
| Device or other IDs → **Device or other IDs** (Firebase Analytics app instance ID; no advertising ID) | Yes | Optional (Settings → Help improve Pavurio) | Analytics |

Everything else is not collected. There is no device location (no GPS) and no contacts.

**Walk weather is switched off in this build** (Open-Meteo's free API isn't licensed for commercial apps; `extra.weatherApiKey` turns it back on with a commercial plan). With it off, no city or location leaves the phone. If it is turned on, declare **Location → Approximate location** (city level counts as approximate location for Google Play): collected and shared with the weather provider, optional, for App functionality — and update the privacy policy first.

**Is data processed ephemerally?** No.

**Account deletion URL** (asked separately in App content → Data deletion): https://pavurio.com/delete-account.html

**App access** (App content → App access): All functionality is available without special access. No login is needed, because a guest account is created automatically.

**Permissions to justify:**

- **Exact alarms (`SCHEDULE_EXACT_ALARM`):** "Care reminders fire at the exact times the user sets for feeding, medication and walks."
- **Camera:** only when the user chooses to photograph a document or a moment.
