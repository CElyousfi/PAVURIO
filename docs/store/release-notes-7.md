# Release notes: Android build 1.0.0 (7)

Paste each block into Play Console → the release → "Release notes", in its language tag. Each is under Play's 500-character limit.

<en-US>
- A care plan made for your pet: meals, walks, portions and reminders, set from their age and size, and updated as they grow
- Easier setup: the keyboard no longer hides what you type, and Pet Studio lets you choose a coat and collar
- Explore: everything Pavurio does, in one place
- More reliable start-up
- Large dogs: weights up to 120 kg / 264 lb
- Safer backup: photos that can't be saved are listed so you can fix them
</en-US>
