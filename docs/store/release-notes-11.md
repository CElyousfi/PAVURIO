# Release notes: Android build 1.0.0 (11)

Built from `main` at `6ce90d7`: the first-use repair and fixes from builds 7–10, plus the Android UI pass.
Paste each block into Play Console → the release → "Release notes", in its language tag. Each is under Play's 500-character limit.

<en-US>
- Typing is easier: the keyboard never covers what you type
- Looks right on every phone: small screens, tablets and foldables, open or closed
- Changing your phone's text size no longer loses your place
- Full screen on Android: swipe up from the bottom to show the navigation bar
- Setup no longer freezes at the last step
- Tap the next care on Home to log it straight away
</en-US>
